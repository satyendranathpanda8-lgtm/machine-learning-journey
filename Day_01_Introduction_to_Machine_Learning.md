# Day 01 — Introduction to Machine Learning

## What is Machine Learning?

**Machine Learning (ML)** is a field of **Computer Science** that uses **statistical techniques** to give computer systems the ability to **learn from data without being explicitly programmed**.

---

## Traditional Programming

In traditional programming, we provide the **data** and the **program** to the computer, and the computer produces the **output**.

```text
Data ──────────┐
               │
Program ───────┼──→ [ Computer ] ───→ Output
```

### Traditional Programming

**Input:** Data + Program  
**Output:** Result

---

## Machine Learning

In Machine Learning, we provide the **data** and the expected **output** to the computer, and the computer learns the **program/model** from them.

```text
Data ──────────┐
               │
Output ────────┼──→ [ Computer ] ───→ Program
```

### Machine Learning

**Input:** Data + Output  
**Output:** Program (Model)

---

## Key Difference

| Traditional Programming | Machine Learning |
|---|---|
| Data + Program → Output | Data + Output → Program |
| Rules are explicitly written by the programmer | Rules/patterns are learned from data |
| Computer follows predefined instructions | Computer learns patterns from examples |

---

### Summary

> **Traditional Programming:** We tell the computer **how to solve the problem**.  
> **Machine Learning:** We give the computer **data and examples**, and it learns **how to solve the problem**.
